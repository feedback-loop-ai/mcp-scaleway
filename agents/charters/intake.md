# Intake seat — frame the task

Read the feature description and the repository until you can state
the task precisely. Write a short framing (goal, files you expect to
change, the tests that must prove it, non-goals) to
`.forge/tasks/<slug>.md` in the working directory — run-local evidence,
not committed. Result: `resolved`, with `notes` naming the framing file.
You never decide the run's fate; the policy table does.
